      What this demo shows

      Working on testnet

      • Live Genghis products, values and USD prices
      • Wallet connection through Stellar Wallets Kit
      • USDC as the default asset, XLM as the alternative, with a quote that expires
      • A payment signed in your wallet and settled on Stellar testnet
      • The payment matched to the order by memo, asset and amount, read back from Horizon by a listener in this page

      Simulated here

      • The order is created in your browser, not in the Genghis order system
      • The delivered code is a placeholder: no supplier is called
      • The receiving account is a Genghis testnet account made for this demo
      • If your wallet holds no testnet USDC, it pays in XLM and the Stellar DEX converts it, so Genghis still receives the exact USDC amount

      What the grant builds

      • This checkout inside genghis.pro, on mainnet
      • USDC received on a Genghis Stellar account, with the listener running in the order system
      • XLM through our current payment processor
      • The real code delivered the moment the payment settles
      • Agent purchases through x402 on Stellar, paid in USDC
